# Aurora Desk

Internal notes for the screenshot project.

## Why this exists

Aurora Desk is a **fictional** product used to photograph Midnight Royal — the colour theme, Material icons, and Fira Code ligatures in a realistic layout.

## Colour cues to look for

| Role | Colour |
|------|--------|
| Keywords / headings | muted purple |
| Functions / links | clear blue |
| Strings | soft green |
| Types / warnings | muted yellow |
| Comments | deep blue |

Visit the [Midnight Royal Starship theme](https://github.com/mcintosh101/starship-midnight-royal) for the matching prompt.
